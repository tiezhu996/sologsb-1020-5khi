# 档案元数据核对台

`sologsb-1020` 是一个用于口述史与手稿档案元数据比对的本地优先前端工作台，使用 Qwik、TypeScript 和 Qwik UI 构建。

## 功能

- 导入 A / B 两组记录，支持 JSON 数组、制表符和竖线分隔文本。
- 按标题、日期、人物、地点和编号加权匹配，显示综合分数与判断依据。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略，支持批量操作。
- 合并时逐字段并排展示 A / B 来源，每个冲突字段可单独保留或拼接。
- 保存原始记录、字段来源选择、合并结果和忽略动作，形成完整审计轨迹。
- 支持撤销重做、离线 localStorage 保存和 JSON 核对包导出。
- 大量记录采用分批窗口渲染，匹配计算限制每条记录的候选数，避免一次挂载全部行。

## 技术栈

- Qwik 1.20
- TypeScript 5.9
- Qwik UI Headless `@qwik-ui/headless`
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

静态产物输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1020 .
docker run --rm -p 10020:80 sologsb-1020
```

nginx 在容器内监听 `80`，宿主端口 `10020` 由根端口表或运行命令映射。

## 数据说明

记录和审计轨迹保存在当前浏览器（localStorage）。导入新记录后自动重新计算候选匹配，但不会自动确认或覆盖任何字段。

## 并发版本保护（本地工作区 v2）

两个核对页同时处理同一工作区时，不再允许“后保存盖掉先保存”：

- **版本凭据 / 编辑权**：每批确认、忽略、合并、导入或回退提交前，先领取一把带 `baseRevision` 的短期编辑权（10 秒 TTL，过期自动释放，崩溃不留死锁）。提交时重读存储版本，版本落后就拦住写入。
- **冲突拦截与差异**：版本落后时本次写入不会发生，冲突弹窗列出对方在此期间的动作、领取 / 尝试 / 最新三个版本号、记录字段级差异、匹配状态变化，以及本批被拦下的记录对；看清差异后可“重新领取编辑权并重放本批”，或放弃本批保留对方版本。
- **检查点 / 恢复点**：每批动作前先落检查点（含动作前完整快照与被取代的记录对，最多保留 15 个）。刷新或崩溃导致提交中断时，下次启动自动回到最近检查点并展示受影响记录对；也可在“恢复点”页签手动回退。提交成功后残留的中断标记不会造成误回滚。
- **撤销 / 重做**：同样经过编辑权与版本闸门；基于旧快照的撤销不能跨版本覆盖对方工作。
- **旧版迁移**：旧的 `v1` 裸状态首次打开时自动迁移为带版本的 `v2`，原始 v1 数据与迁移副本都保留。
- **读取失败保护**：v2 数据无法解析时不删除、不覆盖原件，先把损坏内容隔离到带时间戳的键，再导出含原文的 JSON 错误包，并尝试从 v1 兜底启动。

存储键（均在 localStorage）：

- `sologsb-1020-workspace-v2`：当前工作区状态（含单调版本号 `revision`）
- `sologsb-1020-workspace-v2::checkpoints`：检查点栈
- `sologsb-1020-workspace-v2::lease`：编辑权租约
- `sologsb-1020-workspace-v2::commit`：提交进行中标记（崩溃恢复用）
- `sologsb-1020-workspace-v2::quarantine-<时间戳>`：读取失败时隔离的损坏原件
- `sologsb-1020-archive-state-v1` 及 `::migration-backup`：旧版原件与迁移备份
