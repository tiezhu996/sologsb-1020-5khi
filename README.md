# 档案元数据核对台

`sologsb-1020` 是一个用于口述史与手稿档案元数据比对的本地优先前端工作台，使用 Qwik、TypeScript 和 Qwik UI 构建。

## 功能

- 导入 A / B 两组记录，支持 JSON 数组、制表符和竖线分隔文本。
- 按标题、日期、人物、地点和编号加权匹配，显示综合分数与判断依据。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略，支持批量操作。
- 合并时逐字段并排展示 A / B 来源，每个冲突字段可单独保留或拼接。
- 保存原始记录、字段来源选择、合并结果和忽略动作，形成完整审计轨迹。
- 支持撤销重做、离线 localStorage 保存和 JSON 核对包导出。
- 多个核对页面同时处理时，提交前领取编辑权并携带当时版本做乐观锁校验；版本落后直接拦住写入，弹窗指出对方动作、版本与被取代的记录对（含字段级差异），看完差异后一键重新领取并在新版本上重做。
- 每批确认、忽略、合并、导入前都落盘独立检查点（最近 20 条）；刷新或崩溃后按进行中标记自动回到最近检查点，并列出被回退的记录对；也可在「检查点」弹窗手动回到任意一条。
- 旧版 v1 本地数据启动时自动迁移；主数据或检查点读取失败时保留原数据到隔离区，可导出错误包。
- 大量记录采用分批窗口渲染，匹配计算限制每条记录的候选数，避免一次挂载全部行。

## 技术栈

- Qwik 1.20
- TypeScript 5.9
- Qwik UI Headless `@qwik-ui/headless`
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

静态产物输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1020 .
docker run --rm -p 10020:80 sologsb-1020
```

nginx 在容器内监听 `80`，宿主端口 `10020` 由根端口表或运行命令映射。

## 数据说明

记录和审计轨迹保存在当前浏览器。导入新记录后自动重新计算候选匹配，但不会自动确认或覆盖任何字段，也会保留既有匹配的确认 / 忽略 / 合并结论。

本地存储分为互不覆盖的几个键（见 `src/utils/workspace.ts`）：

| 键 | 内容 |
| --- | --- |
| `sologsb-1020-archive-v2` | 版本信封：版本号、持权页面、最后动作与核对数据 |
| `sologsb-1020-checkpoints-v2` | 最近 20 条提交前检查点（主数据损坏时仍可恢复） |
| `sologsb-1020-edit-lease` | 编辑权租约（20 秒 TTL，提交期间短暂持有） |
| `sologsb-1020-pending` | 进行中标记，用于判断崩溃发生在保存前还是保存后 |
| `sologsb-1020-errors-v2` / `sologsb-1020-error-*` | 读取失败时保留下来的错误包与原始数据隔离副本 |
| `sologsb-1020-archive-state-v1` | 旧版数据，自动迁移后原样保留 |

写入采用乐观锁：提交基版本必须等于信封当前版本，否则整笔写入（连同撤销栈）回滚，冲突记录对与字段差异在弹窗中列出，不会把另一个页面的复核盖回去。
